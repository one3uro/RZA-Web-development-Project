# RZA Webpage Showcase

A full-stack, local web application developed as a school project based on a specific academic design brief. The project demonstrates core capabilities in connecting an interactive user interface to a functional local database backend.

Because this project runs locally via a development environment, a full video walkthrough has been prepared to showcase the entire platform's features.

## 🛠️ Tech Stack & Architecture

The application relies on standard web technologies working hand-in-hand to process data and handle user actions:

* **Frontend:** HTML, CSS, JavaScript (client-side logic)
* **Backend:** PHP (Form handling, session management, and server routing)
* **Database:** SQL / MySQL (Managed locally via XAMPP's phpMyAdmin)

---

## Project Highlights

* **Brief-Driven Development:** Built systematically to meet specific requirements and constraints provided in a computer science school brief.
* **Full-Stack Execution:** Integrates database queries with frontend rendering, allowing seamless data flow from user input to persistent storage.
* **Local Hosting Pipeline:** Engineered and tested using a local XAMPP stack server environment.
